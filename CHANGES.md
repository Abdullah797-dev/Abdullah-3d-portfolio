# One theme, end to end — Virenhold "Classic Green Hills" (Nov 2026)

The whole site now lives in one landscape, like the reference: no more flat ivory pages.

- **Landscape:** `public/backgrounds/hills.jpg` (2560×1440) — rolling green hills, golden
  sunlit slopes, oaks along the valley folds, soft haze. Rendered in 3D and colour-graded
  (no stock photo was available offline). `hills-1280.jpg` and `hills-blur.jpg` are smaller /
  blurred versions. To use your own photograph, replace `hills.jpg` (same name), then re-make

  section and softens into the blurred version as you scroll past the hero.
- **Sections:** transparent cinematic veils + frosted-glass cards, white serif headings, sage
  body, lime accents. All ivory-only colour classes were remapped.
- **CTA:** one style everywhere — white pill, black text, dark square arrow tile (hero, About,
  Contact). Contact opens with a full-bleed CTA band over clear hills.
- **Footer:** frosted glass meta row (© · Karachi · All Rights Reserved · Top), an evenly spaced
  link row, giant gradient-fading "HAFIZ ABDULLAH" wordmark, "Personal & client use" pill.
- **Hero:** the photo landscape with 0.3× parallax; the character now stands in it on a soft
  meadow patch (the separate cartoon hill was removed).

# UI/UX + 3D upgrade — what changed

No text, projects or page structure were changed. Only styling, motion and fixes.

## New files
- `src/lib/scroll-store.ts` — shared scroll state and `scrollToId()` (works with Lenis)
- `src/hooks/use-heavy-3d.ts` — true only on wide screens with a mouse and 4+ CPU threads
- `src/components/effects/scroll-effects.tsx` — GSAP ScrollTrigger: section fades, parallax, hero fade, camera progress
- `src/components/effects/mobile-wave.tsx` — light 2D wave for phones and tablets
- `src/components/preloader/counter-preloader.tsx` — plain 0 to 100 counter (replaces the water preloader)
- `src/components/cursor/glow-cursor.tsx` — glowing dot cursor (replaces the droplet cursor)

## Rewritten
- `scene/hero-scene.tsx` — full-bleed 3D scene behind the hero text
- `scene/scroll-camera-rig.tsx` — one camera rig for mouse + scroll
- `scene/water-shader.ts` — wave phase fix, soft rim glow, fades to transparent at the horizon
- `effects/smooth-scroll.tsx` — Lenis driven by the GSAP ticker
- `effects/tilt-card.tsx`, `background-water-layer.tsx`, `wave-reflection.tsx`
- `sections/skills-section.tsx` — floating glowing pills (same names and levels)
- `sections/hero-section.tsx` — same content, new backdrop

## Fixed
- Water speed no longer jumps when you scroll (phase is accumulated, not `speed × time`).
- Mouse and scroll no longer fight over the camera.
- Tilt card glow now shows. Text is no longer pushed forward in Z, so it stays sharp.
- No HDR download (`Environment preset`). Light cards are built locally.
- Canvas pauses when the hero is off-screen. It falls back to the 2D wave if WebGL fails.
- Removed broken meta links: `/favicon.ico`, `/apple-touch-icon.png`. Removed an unverified Twitter handle.
- Dead `href="#"` on the Storyboard link is now a button.
- Light mode contrast: `--sun` and `--sea` are darker so small text passes.
- Sitemap date updated.
